# Smart AIO実行後評価

実行したSkillそのものではなく、独立した評価役として成果物と記録を確認する。

## 手順

1. `run_id`、期待チェックポイント、実際のチェックポイント、段階レビューを受け取る。
2. 最初に満たされなかった工程を特定する。
3. 入力不足、設計不足、実装不具合、外部接続、運用ミスを分ける。
4. `evaluate-skill-run` で失敗段階と証拠を返す。
5. Skill変更が必要な場合だけ `$fix-skill` へ渡す。

評価区分は [実行評価基準](references/runtime-evaluation.md) に従う。
