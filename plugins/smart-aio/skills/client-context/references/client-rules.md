# 顧客確認ルール

確認対象は `SMARTAIO本番Drive直下クライアントフォルダー` と、そのクライアントフォルダー内または設定で確認した `記事制作シートURL` が示すクライアント専用の `基本情報`、`企画確認`、`記事一覧`、`キーワード`、`クラスター`、`設定`。最低限、`client_id`、顧客状態、制作AI、独立レビューAI、人の最終承認ルール、サービス、対象読者、禁止表現、プロフィールウィジェット用の著者情報、出力先、設定版を確認する。記事制作シートURLがない、6シートの名称が違う、企画確認・記事一覧・キーワード・クラスターの列が `system-contract.mjs` の定義と一致しない場合は `BLOCKED` とする。

`基本情報`、`企画確認`、`記事一覧`、`キーワード`、`クラスター`、`設定` の6シートを表示する。`基本情報` はホーム兼クライアント情報とプロフィールウィジェット用の著者情報、`企画確認` は初回の記事方向性確認、`記事一覧` は日常の制作確認、`キーワード` は検索語履歴、`クラスター` はクラスター一覧とピラー一覧の同時確認に使う。`設定` は確認可能にするが、保護されたプロンプト本文はSkills正本から読み込み、担当者が変更しない。

過去記事、重複確認、内部リンク候補は同じクライアント専用制作シートだけから取得する。中央管理台帳は顧客と制作シートの索引、実行履歴、監査のために使い、記事制作の正本にはしない。

顧客状態が「停止」または「アーカイブ」の場合は処理を止める。利用者の対象顧客操作権限、または完成物を承認する人の最終承認権限が確認できない場合も `BLOCKED` とする。人の氏名は完成物を承認した時点で記録すればよく、記事制作開始時の固定入力にはしない。
